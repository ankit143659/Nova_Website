2. BUSINESS WORKFLOW & PURPOSE
---------------------------------------------------
Purpose: We sell premium AI companion and system automation software (Nova, MJ, MAX) as digital software licenses.
Target Platforms: Windows, Android, MacOS.
Digital Delivery Workflow:
  1) User selects their Operating System (Windows / Android / MacOS / Combo).
  2) User picks an AI Model/Product (Nova, MJ, Unified Combo, or Custom).
  3) User proceeds to the Product Details page where they can increase quantity (with bulk discounts) and apply redeem codes.
  4) User clicks "Proceed to Secure Checkout".
  5) Razorpay payment gateway opens up for Indian Rupees (INR) payment.
  6) After successful payment, a Payment Form collects the customer's Name and Email.
  7) An automated WhatsApp message is generated with the invoice and payment ID, directing the user to our WhatsApp numbers to receive their software (EXE/ZIP) and activation key within 5-15 minutes.
